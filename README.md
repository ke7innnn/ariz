# The Social Vine Studio

> Independent Creative & Social Direction for Ambitious Brands Across India.

**Live Website:** [https://the-social-vine.vercel.app](https://the-social-vine.vercel.app)

---

## Overview

The Social Vine Studio is a luxury architectural digital experience engineered with high-end motion design and typography inspired by modern editorial portfolios.

### Key Highlights

- **Cinematic Opening Intro**: Choreographed multi-stage brand reveal with blueprint hairlines and typography masks.
- **Scroll-Driven Hero**: 3D perspective statement with kinetic letter shifts and dynamic architectural blueprint guidelines drawn on scroll.
- **Scroll-Pinned Selected Work Gallery**: Sticky vertical-to-horizontal translation, inner image stereoscopic parallax, dynamic live counter (`01 / 05` through `05 / 05`), and progress hairline indicator.
- **Luxury Retainers & Pricing Section**: Transparent retainers (Starter, Growth, Premium) with on-site model shoot add-on panel and interactive pill selectors.
- **Interactive Concierge & Modal Inquiry**: One-click booking flow pre-filled directly into WhatsApp Concierge.
- **Editorial Dark Noir Aesthetic**: Fluted glass gradient canvas, custom difference-blend cursor, and typography hierarchy.

---

## Tech Stack

- **Framework & Bundler:** [Vite](https://vitejs.dev/)
- **Core:** HTML5, Modern Vanilla JavaScript (ES Modules)
- **Styling:** CSS3 Custom Properties (Design System Tokens, Glassmorphism)
- **Animation:** [GSAP](https://greensock.com/gsap/) & native `requestAnimationFrame` lerp interpolation
- **Hosting:** [Vercel](https://vercel.com/)

## Getting Started Locally

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/yoooohaen-blip/the-social-vine.git

# Navigate to project directory
cd the-social-vine

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
